# FitPlan 智能健身计划生成器

一个纯前端的健身计划推荐网页。用户回答 10 个问题后，页面会依据训练年限、目标、器材、可训练天数等条件，生成一份可执行的每周训练计划。

## 功能特点

- 10 步问卷：目标、周期、性别、训练年限、每周天数、单次时长、器材、薄弱部位补强、避让部位、是否练腿。
- 规则推荐引擎：按训练年限选择分化方式（全身 / 上下肢 / 推拉腿），细分到上胸、下胸、中缝、肩中束等具体部位。
- 个性化处方：复合动作与孤立动作分别给出组数、次数、休息时间；减脂 / 塑形按比例安排有氧，增肌 / 力量不安排有氧。
- 动作示意图：纯 SVG 火柴人动画，带对应器械（杠铃、哑铃、绳索、跑步机等）与发力高亮，按部位推荐跟学博主。
- 平替按钮：器材缺失时，一键替换为练同一部位的其它动作。
- 无需注册、无需后端，打开即用，适配手机与电脑。

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 页面结构：首页、问卷、结果页 |
| `styles.css` | 样式与响应式布局 |
| `app.js` | 核心逻辑：问卷、推荐引擎、计划生成、渲染 |
| `animate.js` | 动作示意图（SVG 动画）与博主推荐 |
| `test-engine.js` | 引擎测试脚本（Node 环境运行，1620 组测试） |

## 本地运行

直接双击 `index.html` 即可在浏览器打开；或在项目目录执行：

```bash
python3 -m http.server 8899
```

然后访问 `http://127.0.0.1:8899/`。

运行引擎测试：

```bash
node test-engine.js
```

## 技术栈

HTML5 + CSS3 + 原生 JavaScript，无框架、无后端、无外部依赖，可直接部署到 GitHub Pages。

## 制作说明

本项目为《人工智能基础与应用》课程大作业。

- **本人承担**：确定选题（健身计划），提出每一轮功能需求与改进意见，试用并对推荐结果做专业判断（训练年限分化、训练频率、部位容量、恢复时间、力量有氧比例等），最终取舍 AI 给出的方案。
- **AI 辅助**：根据需求编写与迭代全部代码、绘制 SVG 动作示意图、编写测试用例、协助整理文档。所有功能均在本地可运行验证。

项目经过六轮迭代：问卷细化 → 动作图解与器材规则 → 训练分化科学化 → 处方与容量控制 → 练腿偏好与有氧取舍。完整的人机协作交互记录见实验报告附件。
